# DripTrace

## DripTrace hardware facts

Full measured facts (library bodies, raw results, website audit): `docs/hardware/DRIPTRACE_FACTS.md`. Measured 2026-10-08.

- Board: ESP32-S3-WROOM-1 N16R8 (rev 2, 16 MB flash, 8 MB PSRAM) on **COM3**, CH343 UART0 (`VID_1A86&PID_55D3`), 115200 baud.
- FQBN: `esp32:esp32:esp32s3:PSRAM=opi,FlashSize=16M,PartitionScheme=app3M_fat9M_16MB,CDCOnBoot=default,UploadMode=default`
- arduino-cli: bundled with IDE 2.3.10 at `%LOCALAPPDATA%\Programs\Arduino IDE\resources\app\lib\backend\resources\arduino-cli.exe` (1.5.1). Always pass `--config-file "C:\Users\G M HRISHI\.arduinoIDE\arduino-cli.yaml"`, or it picks the stale OneDrive library folder.
- Core 3.3.12 (IDF v5.5.5). Libraries: HX711 **Rob Tillaart 0.6.5** (not bogde), SparkFun MAX3010x 1.1.2, Adafruit ST7735/ST7789 1.11.0, Adafruit GFX 1.12.6.
- HX711: **−255.85 counts/g** (full − empty bottle = 100.5 g; second loading gave −226.25), 10.9 sps, noise 0.6–1.3 g, zero repeatability 4.3 g, 60 s wander up to 11 g peak-to-peak. Load makes raw more negative.
- Empty 100 mL bottle ≈ **16.0 g**; full bottle gross ≈ **116.5 g** (109.2 g on another loading).
- HX711 VCC loss → `is_ready()` true with raw exactly 0; DT or SCK loss → `is_ready()` false (library `read()` then blocks forever).
- MAX30102 at I2C 0x57. Closest to smartwatch: SparkFun default `(0x1F,4,3,400,411,4096)` per-sample (measured 50 sps). Config `(0x1F,4,2,100,411,4096)` = 25 sps.
- **Firmware v3 (current): `firmware/driptrace_v3/`** in this repo. Credentials (WiFi, RTDB secret, hotspot password) live in git-ignored `secrets.h`; `secrets.example.h` lists the fields. Never print the secret; grep staged diffs for it before every commit. v2 in `Downloads\driptrace_esp32s3_firmware_v2\` is superseded.
- v3 tabs: `vitals_ml.h` (raw-RR filter, rhythm model, patient HR baseline in NVS `dtml`, possible-unresponsive rule), `rhythm_model.h` (generated by `tools/ml/train_rhythm.py`, do not hand-edit), `offline_log.h` (1 Hz 16-byte records on FFat, NVS `dtlog`, backfill to `history/<bed>` keyed by epoch ms), `local_web.h` (hotspot `DripTrace-<bed>` at http://192.168.4.1).
- MAX30102 in v3: 50 sps `(0x1F,4,3,400,411,4096)`, pairs averaged to 25 sps for the SpO2 algorithm; finger-off debounced 1 s; motion holds last HR/SpO2 for 8 s.
- Live contract (`beds/<bed>`): `sensorOnline` = load cell connected (not finger); `weightGrams` = gross bottle weight; `lastUpdated` epoch ms; plus `finger`, `signal` (no-finger|acquiring|ok|motion|offline), `rhythm` (regular|irregular|unknown), `irregularProb`, `hrLow`/`hrHigh` (once learned), `baselinePct`, `hrOutOfRange`, `unresponsive`(+`unresponsiveWhy`), `backlog`, `wifi`, `bed`. Dashboard derives `dropsPerMin` (20 gtt/mL) in `src/lib/reading.js`.
- History contract (`history/<bed>/<13-digit epoch ms>`): `t`, `flowRateMlPerHr`, `bottlePercentRemaining`, `weightGrams`, `sensorOnline`, `bottleEmpty`, optional `heartRate`, `spo2`, `irregularProb`, `rhythm`, `unresponsive`, `motion`, `approxTime` (boot never NTP-synced; time estimated). No RTC on the board.
- Serial commands (115200): `sim regular|irregular|unresponsive|off` (demo injection), `baseline reset` (new patient).
- Planned, NOT implemented: two SG90 servos for backflow prevention (pins TBD). Do not write servo firmware until asked.
- Git: commit and push regularly; commit messages carry no Claude attribution.
- Diagnostic sketch: `tools/diag/driptrace_diag/` (no Firebase writes); logs in `tools/diag/logs/` (git-ignored).
